## 🎨 Colors
| Name       | Hex       | Variable           | Use Case             |
|------------|-----------|--------------------|----------------------|
| Background | `#000000` | `--color-bg`       | Main canvas          |
| Foreground | `#FFFFFF` | `--color-fg`       | Main text/lines      |
| Accent     | `#FF3B30` | `--color-accent`   | Interactions/CTAs    |
| Border     | `#1A1A1A` | `--color-border`   | Grid lines/Dividers  |
| Muted      | `#808080` | `--color-muted`    | Metadata/Small text  |

## 🔤 Typography
- **Display (Serif):** *Serrif* (Fallback: Playfair Display)
- **Body (Sans):** *Saans* (Fallback: Inter)

### Scale
- **Display XL:** 120px / 0.9 line-height / -0.02em tracking
- **Heading L:** 40px / 1.1 line-height / 0.05em tracking (Uppercase)
- **Body M:** 16px / 1.6 line-height
- **Caption S:** 12px / 1.2 line-height / 0.1em tracking (Uppercase)

## 📐 Spacing & Layout
- **Base Unit:** 8px
- **Grid:** 12-column fluid
- **Borders:** 1px solid
- **Radius:** 0px (Sharp edges)

## ✨ Motion
- **Easing:** `cubic-bezier(0.23, 1, 0.32, 1)` (Circ Out)
- **Transitions:**
    - Fast: 200ms
    - Standard: 400ms
    - Reveal: 800ms
